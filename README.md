# 灯油配送台帳 v2（住所なし）

iPad・スマホ・パソコンのブラウザから、顧客検索と配送記録を行うStreamlitアプリです。

## 今回の重要な仕様

- 住所は保存・読込しません。
- お客様名を一文字入力すると、候補が絞り込まれます。
- 候補には「名前・顧客コード・エリア・R区分」を表示します。
- 顧客コードを正として保存します。
- 配送記録は保存前に確認画面を表示します。
- レンタル顧客は月1回の伝票計上を確認できます。
- 記録の修正履歴用に、作成日時と更新日時を保存します。

## データ保護

顧客データと配送実績は住所なしの非公開Google Sheetに保存します。公開GitHubリポジトリには顧客名・コード・件数・実績CSV・接続先IDを置きません。

## 画面

1. **配送入力**：名前予測候補から顧客を選び、数量・訪問結果・伝票を登録
2. **顧客検索**：5〜8月実績とアプリ登録後の履歴を表示
3. **本日の記録**：日報集計、記録修正
4. **月間チェック**：エリア別集計、R顧客の伝票確認
5. **接続・使い方**：接続状態と操作説明

## ローカルで確認する

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
streamlit run app.py
```

ローカル確認用CSVを別途配置した場合だけローカル確認モードを利用できます。公開リポジトリには実データを含めません。

## Streamlit CloudとGoogle Sheetsを接続する

1. 住所なしGoogle Sheetを、Google Cloudのサービスアカウントの`client_email`へ編集者として共有します。
2. Streamlit CloudのSecretsへ`gcp_service_account`と`spreadsheet_id`を登録します。
3. `APP_PASSWORD`へログインパスワードを登録します。
4. アプリを再起動し、「接続・使い方」が「Google Sheets接続モード」になっていることを確認します。

秘密鍵をGitHubや共有ファイルへ貼り付けないでください。

## Google Sheetsのタブ

- `顧客マスター`
- `月次実績`
- `配送記録`
- `タンク在庫`
- `設定`

アプリは上記タブだけを参照します。住所入りの既存「灯油配送」シートは参照しません。
